# Leeway for Codex

Room to work, without the drift. One drive your team and its agents share: everyone sees what's true, every move is on record, and any mistake can be undone.

This plugin connects Codex to your Leeway drive and adds skills for saving, finding, undoing, working in a workspace and leaving a hand-off note.

## Install

```sh
codex plugin marketplace add supersethvos/leeway-codex
codex plugin add leeway@leeway
codex mcp login leeway
```

The last command opens leeway.to in your browser. Sign in with your passkey (or make a free drive), then choose the drive or folder Codex may use and what it may do there.

In the Codex app, add the marketplace `supersethvos/leeway-codex`, install Leeway from Plugins, and choose Connect.

Then ask, for example: "Save a short summary of this session to /Notes/summary.md in my Leeway drive."

To remove Codex's access at any time, go to https://leeway.to/activate?people.

More: https://leeway.to/agents/ · Support: https://leeway.to/support
